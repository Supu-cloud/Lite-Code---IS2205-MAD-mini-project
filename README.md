# <LiteCode/> - Modern Mobile Text Editor

<LiteCode/> is a professional-grade mobile IDE and text editor designed for developers and power users. It provides a specialized environment for Kotlin development, web experimentation (HTML/CSS/JS), and rich-text document management, all wrapped in a sleek, high-tech interface.

Developed as a mini-project for **IS2205: Mobile Application Design and Development (2026)**.

## 🚀 Key Features

### 1. Tri-Mode Workspace
*   **Kotlin Mode**: Write and execute Kotlin code. Integrated with a remote Flask compiler server for real-time results.
*   **Web Mode**: An offline playground for HTML, CSS, and JavaScript. Combines all three into an instant preview with a built-in JS console.
*   **Text Mode**: A dedicated rich-text editor for notes and documents with support for advanced formatting.

### 2. SQL Room Database Persistence
*   **Recent Files List**: Automatically tracks opened and saved files across all modes for quick one-tap access.
*   **Snippet Library**: Save reusable blocks of code or text to a local database and insert them into any file instantly.

### 3. Professional Editor Tools
*   **Find & Replace**: Real-time literal search with match highlighting, "2 of 5" counter navigation, and global "Replace All" functionality.
*   **Rich Text Formatting**: Apply Bold, Italic, Underline, custom Font Sizes, and vibrant Colors to specific text ranges in Text mode.
*   **Word Wrap**: Toggle between single-line code view and wrapped paragraph view for maximum readability.
*   **Independent History**: Each workspace mode maintains its own Undo/Redo stack.

### 4. Advanced UX & UI
*   **Techie Theme**: A high-contrast midnight gradient theme featuring an animated "code rain" splash screen and professional monospace typography.
*   **Material 3 Design**: Smooth color animations, consistent Material iconography, and 48dp accessible touch targets.
*   **Soft Wrap Support**: Handle large paragraphs and code blocks with ease.

## 📦 Persistence Formats
*   `.kt`, `.java`, `.py`, `.c`, `.cpp`: Standard source code files.
*   `.html`, `.css`, `.js`: Standard web files.
*   `.txt`: Universal plain text.
*   `.lctxt`: LiteCode-specific rich-text format (JSON serialized) for preserving styles and colors.
